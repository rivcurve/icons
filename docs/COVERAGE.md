# Refined coverage

Rivcurve expands by interface task. Each series ships through the same canonical 24 × 24 SVG source, searchable catalog and size comparison. Names in the manifest remain the public identifiers.

## Added after the first documentation pass

| Family | Coverage added |
| --- | --- |
| Navigation | Up/down arrows and the missing chevron directions. |
| Actions | Add, remove, overflow, settings, filtering, editing, copy, delete and reload. |
| Communication | Mail, chat, phone, sending, inbox, mute, link, share and mentions. |
| Utility | Calendar, clock, globe, bookmark, heart and star. |
| Security | Locks, shields, key and visibility. |
| Media | Playback, volume, camera, video and microphone. |
| Status | Information, help, warning, success, failure, removal and loading. |

## Next coverage groups

1. **Forms and account flows.** Inputs, validation, login/logout, access levels, consent, recovery and preferences.
2. **Commerce and delivery.** Products, cart, checkout, orders, refunds, discounts, shipments and tracking.
3. **Content and editing.** Text formatting, clipboard, rich media, cropping, arranging and annotations.
4. **Data and operations.** Sort, dashboards, chart types, imports, sync, alerts, queues and job status.
5. **Devices and the physical world.** Screen sizes, connectivity, travel, maps, buildings and accessibility.

Prefer filling gaps in real interface examples before adding visually close synonyms. Compare family variants together and keep status symbols distinguishable by shape alone.
