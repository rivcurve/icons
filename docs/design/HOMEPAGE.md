# Главная Rivcurve

**Выбрано 22 ноября 2026:** вариант A «Иконки в продукте». [Визуальный референс](homepage-reference.png).

Роль первого экрана — представить Rivcurve как библиотеку для продуктовых интерфейсов. Слева короткое описание Refined, основное действие **Get started** и второе действие **Browse icons**. Справа пример файлового интерфейса на светлом фоне внутри оранжевого поля. Иконки демонстрируются в кнопках и списке в обычном размере. На телефоне пример идёт после обоих действий.

Базовые роли цвета: тёплый светлый фон, тёмный текст, оранжевое поле презентации. Значки и текст в примере должны сохранять контраст. Утверждение относится к направлению, поэтому точные токены, типографика и векторный знак оформляются во время разработки. В примере используются настоящие SVG из исходников, в тексте сайта — реальные имена, число и статус пакетов.

Следом идёт короткая инструкция для React и Vue. Каталог открывается с главной и из навигации. Поиск, размеры 16/20/24 и экспорт SVG принадлежат каталогу. Первый рабочий маршрут: главная → Get started → пример подключения. Второй: Browse icons → поиск → детали.

Next.js App Router со статической сборкой. Первый выпуск: SVG, React, Vue. Flutter остаётся отдельным этапом. Команды публичной установки появляются после выпуска пакетов.
