# Rivcurve · библиотека на первом экране

**Подтверждённый порядок действий:** первым идёт Get started, рядом Browse icons. Рабочее название Rivcurve. Refined — имя набора. Сайт на Next.js. Веб-пакеты React и Vue запланированы для первого выпуска, Flutter — позднее.

## Общая структура

1. Главная объясняет, для чего подходит библиотека, и показывает настоящие SVG в интерфейсе или в серии. Get started ведёт к инструкции подключения. Browse icons открывает каталог.
2. Инструкция даёт короткие примеры для React и Vue с одинаковыми именами иконок. Ссылки и команды публичной установки появляются после выпуска пакетов.
3. Каталог отвечает на вопрос, есть ли нужный символ. Здесь находятся поиск, категории, 16/20/24 px и выбор иконки. В её деталях доступны компоненты и экспорт SVG.
4. На мобильной ширине текст и два действия идут перед примером. В документации и каталоге используется та же типографика и навигация.

## Варианты

- **A. Иконки в продукте.** Тёплый светлый фон, чёрная типографика, оранжевое поле с примером файлового интерфейса. Сильная сторона — иконки видны там, где ими пользуются. Риск — слишком большой пример вытеснит способы подключения.
- **B. Пакеты и набор.** Насыщенный синий первый экран, ниже — код установки рядом с подборкой Refined. Сильная сторона — короткий путь от знакомства к коду. Риск — меньше видно, как формы ведут себя в интерфейсе.

Рекомендация: A как основа для главной и брендового языка. Размещение коротких инструкций и реальной подборки рядом можно оценить по B. Изображения фиксируют композицию. Иконки и данные для реализации приходят из существующих 50 SVG, а команды установки остаются проектными до публикации пакетов.
