# Rivcurve · план продукта

**Утверждено 23 ноября 2026.** Rivcurve — библиотека, Refined — первый стиль, Filled — второй. Текущая основа: 108 SVG Refined, валидатор, сайт на Next.js с каталогом и документацией.

## Что такое Rivcurve

Личный open-source проект и витрина ремесла. Набор контурных и заливных иконок для продуктовых интерфейсов: ясная форма на 16 px, родство внутри семейств, одинаковая геометрия в SVG, React, Vue и позднее Flutter. Коммерческой модели нет: всё бесплатно под MIT.

## Контракт стилей

- Исходники: `icons/refined/<category>/<id>.svg` и `icons/filled/<category>/<id>.svg`. Один ID — оба стиля, валидатор проверяет наличие пары.
- Публикация: `svg/refined/heart.svg`, `svg/filled/heart.svg`.
- React/Vue: отдельные экспорты `HeartIcon` и `HeartFilledIcon` — без пропа `variant`, чтобы tree-shaking оставался точным.
- `strokeWidth` действует только на Refined. `size`, `color` (`currentColor` по умолчанию) и доступное имя есть у обоих стилей.
- Вводить Filled до 1.0 безопасно: в 0.x новые экспорты добавляются минорным релизом.

### Ритм

Без дат. Один минорный релиз — одна завершённая серия: ~20–30 ID в двух стилях, чейнджлог, обновлённый каталог. Патч — исправление формы без смены смысла. Мажор — удаление ID или изменение публичного API.

### Успех

Все три условия:
1. Выпущен 1.0, качество которого не стыдно показать.
2. Набор работает в 1–2 продуктах автора и хотя бы в одном чужом проекте.
3. Первый год после 1.0: **100★ на GitHub** и **200 скачиваний npm в неделю**.

## Общий источник и пакеты

Манифест хранит неизменяемый ID, категорию, поисковые слова и правила отражения для RTL там, где они нужны. Нормализованные данные имеют версию схемы, из них строятся пакеты и каталог. Любая правка проходит через исходный SVG. Публичные имена: `git-branch` в каталоге, `GitBranchIcon` / `GitBranchFilledIcon` в React и Vue, `RivcurveIcons.gitBranch` во Flutter.

В CI: валидация SVG и пар стилей, проверка актуальности сгенерированных файлов, типов и распакованных архивов. Публикация идёт из тега после ручной проверки каталога.

### Flutter

Начальный вариант: SVG в ресурсах пакета и типизированная обёртка над `flutter_svg`. Цвет берётся из темы с явным переопределением, плюс размер и семантика. Замерить размер приложения при импорте одной иконки и всего набора. Если вес или динамическая толщина станут проблемой, сравнить с генерацией рисования из той же геометрии. Голдены сверяются с браузером при 16, 20 и 24 px. [Ресурсы Flutter-пакетов](https://docs.flutter.dev/ui/assets/assets-and-images#asset-images-in-package-dependencies) · [flutter_svg](https://pub.dev/packages/flutter_svg).
